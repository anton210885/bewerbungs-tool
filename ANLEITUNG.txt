BEWERBUNGS-TOOL – INSTALLATION
==============================

Voraussetzungen
- Windows 10 oder 11
- Python 3.10 oder neuer: https://www.python.org/downloads/
  Beim Installieren unbedingt «Add python.exe to PATH» anhaken.
- Internet (beim ersten Start und für die KI)
- Ein eigener KI-API-Schlüssel (z.B. Venice oder OpenAI)

Installation
1. Den Ordner «bewerbungs-tool» aus der ZIP-Datei an einen festen Ort kopieren,
   z.B. nach Dokumente. Nicht direkt vom USB-Stick starten.
2. Im Ordner doppelt auf «start.bat» klicken.
   Der erste Start richtet alles ein und dauert einige Minuten.
3. Der Browser öffnet sich mit dem Tool. Links unter «Einstellungen → API & KI»
   den eigenen API-Schlüssel eintragen.
4. Unter «1. Meine Unterlagen» den eigenen Lebenslauf hochladen.

Starten
- Immer per Doppelklick auf «start.bat». Das schwarze Fenster offen lassen;
  wer es schliesst, beendet das Tool.
- Tipp: Rechtsklick auf start.bat → «Senden an» → «Desktop (Verknüpfung erstellen)».

Daten
- Alle eigenen Daten liegen im Unterordner «data», der Schlüssel in der Datei «.env».
  Beides bleibt auf diesem Computer.
